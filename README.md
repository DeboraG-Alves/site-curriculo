# 💼 Currículo - Débora Guilherme Alves

Este é um projeto de site currículo desenvolvido com HTML5 e CSS3, com o objetivo de apresentar minhas habilidades, experiências e projetos como desenvolvedora front-end em formação.

---
## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Responsividade (Mobile First)

---

## 📌 Funcionalidades

* Layout responsivo
* Apresentação de informações profissionais
* Seção de projetos
* Links para redes sociais

---

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar e consolidar conhecimentos em desenvolvimento front-end, além de servir como portfólio profissional.

---

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, aprendi:

* Estruturação semântica com HTML5
* Organização de layout com CSS3
* Conceitos de responsividade
* Boas práticas de organização de código
